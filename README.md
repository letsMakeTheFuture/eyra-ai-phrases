# EYRA AI Phrases

An AI phrase-suggestion feature for EYRA, an eye-controlled communication system for people with mobility or speech difficulties.

It is built for people who can only move their eyes, such as someone with quadriplegia. Someone asks a question out loud, the app suggests replies, and the user picks one with a blink. Nothing is spoken until the user confirms.

## Pre-existing (before Oct 26, 2026)

The original EYRA eye-control system (gaze navigation, spelling keyboard, text-to-speech).

## New work (hackathon, Oct 26 - Nov 4, 2026)

- Phrase suggestions generated by a Meta open-weight model (Muse Spark, served through Baseten)
- Replies to a question: the app listens to the question through the microphone (or a caregiver can type it) and the model suggests replies that fit
- Short-term conversation memory: the last 4 spoken exchanges are sent with each request, so follow-up questions get coherent replies. A "Start a new conversation" option clears it
- Optional caregiver note (where we are, who is here) that is added to the model's context
- Blink selection: the screen scans through the options, and closing the eyes for about 1 second selects the highlighted one
- Confirmation screen (SPEAK / CANCEL) before anything is spoken
- Labeled fallback: if the model cannot be reached, mock phrases are shown in orange and clearly marked as mock

## How it works

1. The user (or a caregiver) opens "Listen to the question", and someone asks the question out loud.
2. The question is transcribed and shown on screen, so a misheard question is easy to spot.
3. Muse Spark suggests a few short replies.
4. The user selects a reply by blinking, then confirms SPEAK.
5. The reply is spoken aloud and added to the short-term memory.

## Privacy

- The question audio is sent to Google for speech-to-text.
- The transcribed question, the last 4 spoken exchanges and the caregiver note are sent to Muse Spark through Baseten.
- Conversation memory lives only in the running program. Nothing is stored on disk.

## Run

```
python phrases_screen.py             # blink input (camera)
python phrases_screen.py --keyboard  # SPACE key instead of blink
```

Requires Python 3, `PyQt5`, `pyttsx3`, `SpeechRecognition`, `pyaudio`, a working microphone, an internet connection, and a Baseten API key for Muse Spark (see `muse_provider.py`).

## Known limitations

- Speech recognition is currently set to English (`LISTEN_LANG` in `phrases_screen.py`) and works best in a quiet room with a close microphone.
- The model suggests replies, but the user decides. Suggestions are not guaranteed to be right, which is why confirmation comes before speaking.
