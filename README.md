# EYRA AI Phrases
   An AI phrase-suggestion feature for EYRA, an eye-controlled
   communication system for people with mobility or speech difficulties.

   ## Pre-existing (before Oct 26, 2026)
   The original EYRA eye-control system (gaze navigation, spelling
   keyboard, text-to-speech).

   ## New work (hackathon, Oct 26 - Nov 4, 2026)
   - Phrase suggestions generated by a Meta open-weight model
   - Selection by eye, with confirmation before speaking

   ## Status
   Work in progress
